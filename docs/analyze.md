# 统计说明

`python -m auction_game.cli.analyze` 默认分析 `logs/` 下最新的、至少打完一局的真实场次；离线赛要传目录。未完赛的场次只统计已经结束的局。未注明的指标都包含流局日。命中分一律等于总分减拍卖分。

## 阵营（只在团队赛输出）

- **队内撞车**：一天里一个价位上有同一阵营 2 笔及以上正常出价，算一次；三人同价也只算一次。
- **只狙到队友**：超级出价落空，而狙的价位上有正常出价。超级出价不能和自己的正常出价相同，所以那里只有队友的出价。

## 玩家明细

- **单局最高总分**：分独占和并列计局数，并列者每人记一局，全员 0 分也算并列；加赛也算。
- **超级出价净金币**：命中次数 × 悬赏 − 使用次数 × 成本，只算超级出价本身。
- **撞车损失**：被没收的正常出价金币，分两项。"正常出价互撞"是至少两笔正常出价同价，这个价位同时被狙也算在这里；"唯一正常出价被狙"是只有一笔、被超级出价命中。
- **正常出价为零**：不含超级出价。

## 全场指标

- **局末平均金币**：每人每局的局末余额各算一个样本。
- **命中原本互撞价**：命中的超级出价，目标价在当天正常出价里至少出现两次。
- **改变当日结果天数**：正常出价不变，去掉全部超级出价后重算当天，赢家或是否流局变了就计一天。只重算当天，不推演之后的余额和出价。
- **平均出价**：排除流局日，正常出价和超级出价的目标价位都算，所以和玩家的平均正常出价口径不同。
- **平均奖池**：流局日也计入。**获胜价**：只看非流局日。
- **出 0**：含超级出价，所以可能大于各玩家"正常出价为零"之和。

## 模型用量

取自任务日志，成功、失败、取消的任务和每次纠错的回复都算。离线赛不输出。

- **输入**含缓存命中，缓存命中率 = 缓存命中 ÷ 输入。**输出**含推理。
- **请求失败**只计次数，不计入请求，也没有用量。
- OpenAI 协议（`chat`、`responses`）的渠道不报缓存写入，这部分算在未命中的输入里。
- **按任务**另列该类任务最大的单次输入，以及它来自哪名玩家的哪个环节。

用量和花费都是下限：强关时进行中的请求没有记录，被取消的请求断在半路也不记，但它们可能已经收费。

### 花费

按开赛时场次快照里的官方单价（models.dev，每百万 token 美元）和价格倍率，逐条回复计算：

$$\text{花费} = \frac{(\text{未命中输入} \times \text{input} + \text{缓存命中} \times \text{cache\_read} + \text{缓存写入费用} + \text{输出} \times \text{output}) \times \text{倍率}}{10^6}$$

- 单条回复的输入超过某档时，整条按那一档的单价计。
- Anthropic 协议的 1 小时缓存写入按 2 倍 input 计，其余写入按 `cache_write`；来源缺 `cache_write` 或 `cache_read` 单价时按 input。
- 推理按 output 计。来源给推理另标了单价时，表下会提示。
- 来源没有单价的模型显示"无单价"，不计入合计。

## 团队赛对比

`python -m auction_game.cli.team_report` 每个指标一行、每场一列，格子是 `前队:后队`；只有一个值的是两队合并。多场时最后一列是合计，比率的分子分母各自相加；各场阵营不同时不给合计，经济参数不同时照给合计，但在表头下列出不同之处。

### 公共口径

- **人天**：一人一天，每个人天有一笔正常出价。
- **上限**：当天正常出价能出到的最高价。不带狙时是余额和出价上限中较小的；带狙时先从余额里扣掉超级出价成本。
- **余额价**：一个人当天的两种上限（余额不够开枪时只有一种）。只看他能出到多少，不看他当天开没开枪。
- **重算当天**：只重判这一天，按阵营判定，不推演之后的余额和出价。

### 得分

- **第 1 天获胜价均值**：两队合并，只看有人获胜的第 1 天。
- **按天重抽样**：每天两队的分差是一个样本，有放回地重抽 20000 次，取 95% 区间。只对单场有意义，多场不给。

### 超级出价

- **使用**：使用次数 ÷ 人天。**第 1 天开枪**：各局第 1 天的超级出价笔数。
- **去掉超级出价重算拍卖分**：去掉全部、只去前队或只去后队的超级出价，重算当天，奖池记给新的获胜阵营。实际拍卖分减去全部去掉后的拍卖分，就是超级出价带来的拍卖分。
- **从对方换成本队**：实际本队获胜，全部去掉后对方获胜。同队换人不算，所以天数可能少于 `analyze` 的"改变当日结果"。
- **打余额价**：超级出价的价位等于对方某人当天的余额价。分三类：打最高价的（不需要读余额）、第 1 天的（人人余额相同，读余额没用）、其余才是按余额读出的价位。**命中目标是余额价**同样分三类，一笔命中只算一次。
- **集火**：一天里同队 2 笔及以上超级出价打同一价位。**三人同打一价**按天计。
- **打对方昨天的价位**：第 2 天起，价位是同一局前一天对方某人的正常出价。
- **事后最佳固定狙价**：对方当天有人出这个价的天数最多的价位。是事后挑的，高估了实际能做到的命中率。

### 正常出价和金币

- **贴上限**：正常出价等于当天的上限，带狙和不带狙按各自的上限。再按贴没贴上限分别数被狙的笔数。
- **最高三档的正常出价**：出价上限及以下两档，现行参数下是 10–12。
- **复用昨天本队价位**：第 2 天起，正常出价落在同一局前一天本队三人的价位里，自己的也算。
- **平均余额**：出价前余额，按人天平均。

### 队内撞车

- **队内撞车烧掉的金币**：队内撞车价位上本队的出价之和。**全队撞车烧掉的金币**还包括跨队撞车和被狙。
- **只留一人重算**：本队当天没有获胜、又有队内撞车时，撞车价位上只留一人的正常出价，重算当天，看本队能不能因此获胜。

### 价表

每局第 1 天两队的正常出价和重合的价位数，以及所有流局日两队的正常出价。
