# 唯一高价拍卖游戏（最高唯一出价拍卖）

6 名玩家参与的多局拍卖博弈 demo。每局拍卖 3 个胜场，每天拍卖 1 个，所有人同时秘密出价，
出价最高且唯一的玩家获胜；撞车价位作废向下寻找，全撞车则流局顺延。

## 运行

```bash
pip install -r requirements.txt
pytest            # 规则正确性测试
python main.py    # 6 个 RandomBot 跑完整场比赛（含可能的加赛）
```

日志按场次输出到 `logs/<时间戳>_<模式>/`：`match_<n>.json`（结构化完整日志）+ `match_<n>.txt`（可读文本），
AI 模式另有 `ai_<名字>.jsonl`（完整对话 trace）和 `speeches.txt`（发言记录）。`logs/latest` 软链接始终指向最近一次运行的目录。

## 规则要点

- 每局每人 6 枚金币，跨天累积、跨局不继承，局末作废。
- 出价 0-6 的整数，不得超过余额；非法出价记为 0。
- 正常日出价即消耗不返还；流局日全额返还、无分红。
- 分红 = 当天总出价 // 6，余数没收；一局结束当天不分红。
- 每局最多 5 天，流局可顺延；每天开局全员余额为 0 则本局立即结束。
- 5 局后第一名并列则进入加赛，直到第一名唯一。
