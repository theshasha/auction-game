# 对战日志的玩家统计口径

`analyze.py` 读取单场对战目录（`logs/<时间戳>_<bot|ai>/`）中的 `match_*.json`，打印聚合统计和玩家统计。
本文保留原玩家统计规格，整理日期为 2026-10-15；本次仅整理文档，未重新审计实现与统计口径的一致性。

## 输出位置与格式

玩家统计位于聚合经济块（撞车放血、超级出价）之后、“单局 ≥3 胜场”列表之前，既有聚合段的内容与顺序保持不变。
使用纯文本输出，玩家名单取自日志本身，不读取 `config.yaml`。

## 版本检测与降级

- 新格式：首日含 `collision_values`；v6+：`rules_version` 为 `v6` 或 `v7`；其余按旧格式处理。
- 旧格式缺少 `super_uses` 明细：超级出价使用次数从 bids 的 `is_super` 统计；命中率显示 `—`，并标明旧格式命中率不可得。
- 其余指标在上述格式下均可计算。

## 每局胜场矩阵

每名玩家一行、每局一列，单元格取自该局 match 的 `wins` 字段，覆盖全部正赛及加赛。

## 玩家明细

每名玩家一行，按总胜场降序排列：

1. **总胜场**：match `wins` 跨局合计。
2. **局冠军数**：每局胜场最高者为局冠军；第一名并列时每人按 `1/n` 计入。这是统计指标，正式比赛的加赛判定仍遵循比赛规则。
3. **超级出价使用、命中、命中率**：新格式（含 v6/v7）从 `super_uses` 统计；旧格式按上述降级方式处理。
4. **撞车放血**：因撞车被没收的正常出价金币合计，只计正常出价，与聚合段口径一致。
5. **平均正常出价**：非流局日全部有效正常出价的均值，排除流局日，与聚合段口径一致。
6. **每局局末余额**：通过 `recompute_remaining_coins` 重算，逐局列出。
7. **非法出价笔数**：bid `status == "illegal"` 的次数。
8. **出 0 次数**：正常出价为 0 的次数。

## 验证重点

- v7 日志：全部玩家均有八项明细和每局胜场矩阵，数值与原始日志独立重算结果一致。
- 旧格式日志：正常输出，超级出价命中率按约定降级。
- 含加赛日志：胜场矩阵及跨局合计覆盖加赛。
- 使用合成日志执行零网络测试，检查排序、输出位置及既有聚合输出保持不变。
