# 整场流程

## 按任务查代码

- `director.py`：`AIDirector.run()` 按顺序写完整场，各阶段的轮次和信的邮箱也在这里。
- `controller.py`：轮次的并发、单步、暂停、补跑和退出，规则见根目录 `AGENTS.md` 的"暂停、补跑和退出"。

## 原则

- 团队赛每局开始前都跑开局讨论：第 1 局在开局发言之后、规划之前，第 2 局起在整理记忆之后、规划之前。
- 每局第 1 天的出价由本局规划交出，出价轮从第 2 天开始。
- 局末先公布全员发言，再整理记忆，最后规划下一局。最后一局之后没有局末发言，也不整理记忆，直接是最终感言和观众总结。
- 一轮在 controller 确认提交后才往下走：结算、写信、发布都用确认过的结果，所以退出时比赛状态停在这一轮开始时。

测试在 `tests/flow/`，跑整场用 `tests/support/` 里不调模型的玩家。改阶段顺序时，还要用 `tests/integration/` 的完整假模型赛验证。
