# 对战日志的玩家统计口径

每日拍卖奖池直接计分，超级命中另按本场 `super_hit_score` 加分；排名与单局最高都按总分统计。

`python -m auction_game.reporting.analyze` 默认从真实 `ai` 与 `ai-test` 场次中读取最新有效的一场，两种类型同等参与选择；跳过无效场次。显式传入 `logs/<场次>/` 可分析其他类型。比赛数据位于 `data/matches/<补零编号>.json`，打印聚合统计和玩家统计。

## 输出位置与格式

输出分为四个部分：

1. **比赛概况**：场次目录、运行类型、身份与实际模型、名单、已完成局数、拍卖天数及流局比例。
2. **经济与超级出价**：局末金币、撞车损失、超级使用及效果，再展示每日平均出价、平均奖池和获胜价统计。成本、悬赏、超级出价净金币变化分别成行。
3. **玩家明细**：按总分降序，每名玩家一个小块，分别展示拍卖分与超级命中分，次数与金币写明单位。
4. **特殊情况**：非法出价总笔数、出 0 总笔数与 0 价获胜次数。

使用纯文本输出，玩家名单与比赛参数均取自日志，不读取当前的 `game.yaml`、`players.yaml` 或 `config.yaml`。
真实 AI 显示角色身份及实际调用模型；offline 明确标注假模型，配置中的型号单独列出。Bot 标为本地程序。

## 日志要求与参数来源

- 只支持格式版本3，参数和必需结算字段缺失会报错，不从当前配置补值。旧日志原样保留，不迁移。
- 初始金币、日工资、超级成本与悬赏逐局从快照读取，用于余额重放和经济统计；出价上限取 `max_bid`，加赛列号为局号减 `regular_matches`。
- 同一场次各局必须有相同的参数与参赛名单；每日正常出价、该局 `auction_scores` 与 `scores` 必须覆盖同一名单。两个分数字典都要求非负整数，拒绝 bool。名单顺序可以不同。
- 核对奖池滚存、每日得分、每局成绩和累计排名是否一致，流局日的命中分也计入。
- 每局必须完整包含按顺序排列的第 `1..game.max_days` 天；缺天、重复天、乱序或越界均报错。局号必须是唯一的正整数，文件数字编号必须与内容 `match_index` 一致；文件按数字编号读取，不静默去重，错误指出具体文件或局号。
- 可分析未完赛场次中已完成的局，文件须从第1局连续保存，每局包含累计排名。

## 每局分数矩阵

每名玩家块内的“各局总分”取自 match `scores`，“各局拍卖分”取自 `auction_scores`，覆盖全部正赛及加赛，使用 ` / ` 分隔。统计结果分别提供 `score_matrix` 与 `auction_score_matrix`。
玩家明细开头统一标明列序，如 `正赛第 1 局 / 正赛第 2 局 / 加赛第 1 局（总第 3 局）`；各局结束余额沿用同一列序。

## 玩家明细

每名玩家一个小块，按总分降序排列，同分按名字排序：

1. **总分**：match `scores` 跨局合计，行字段为 `total_score`；同时展示拍卖分 `auction_score` 与超级命中分 `super_score`，后者等于总分减拍卖分。
2. **单局最高总分**：分别统计独占最高总分的局数与并列最高总分的局数；每名并列者记完整一局。全员 0 分的局仍按并列最高统计，每人记一局。统计覆盖正赛及加赛，正式比赛的加赛判定仍遵循比赛规则。
3. **超级出价使用、命中、命中率**：从 `super_uses` 统计，如 `使用3次，命中2次（67%）`；无使用时只显示使用0次、命中0次，不计算或展示命中率。
4. **超级出价净金币变化**：命中次数 × 本场悬赏 − 使用次数 × 本场固定成本，单位金币，显示正负号。只计超级带来的直接金币变化，正常出价扣款另计。
5. **撞车损失**：因撞车被没收的正常出价金币合计，只计正常出价，与聚合段口径一致。
6. **平均正常出价（不含流局日）**：非流局日全部正常出价记录的 `bid` 均值，包含非法整单转换后的正常 0；排除超级出价与流局日。
7. **各局结束余额**：根据本局收支重算，逐局列出，单位金币。
8. **非法出价**：bid `status == "illegal"` 的次数。
9. **正常出价为零（含非法转0）**：正常出价为 0 的次数，包含流局日及非法整单转换后的正常 0，排除超级出价 0。

## 聚合口径

- **每日及全天平均出价**：排除流局日，纳入全部出价记录的 `bid`，包含超级狙击数值及非法整单转换后的正常 0。超级狙击数值参与这个均值，实际金币消耗仍为快照中的固定 `super_cost`。因此聚合均价与玩家“平均正常出价”的分母和取值不同。
- **平均奖池**：同一天序号的全部记录均参与，包含流局日及其滚存后的实际奖池。
- **局末平均金币**：每局先按快照重置初始金币；第 2 天起加工资，扣除获胜或撞车的正常出价，再扣超级固定成本、加命中悬赏。每个玩家-局等权参与均值。
- **撞车扣款、超级使用与命中**：包含流局日；撞车扣款只计正常出价，超级成本单列。
- **超级出价净金币变化**：全场悬赏发放总额减去超级成本总额，等于各玩家超级出价净金币变化之和。
- **使用超级出价天数**：当天 `super_uses` 非空就计一天，同一天多人使用也只计一天，包含流局日。
- **命中原本互撞价次数**：逐笔统计 `super_uses` 中的命中；目标价在当天正常报价的有效 `bid` 中出现至少两次就计一次。同一天多人命中同价分别计数，包含流局日；超级报价不参与正常报价计数，非法整单转换后的正常 0 保持为 0，不使用 `raw_bid` 或历史 `collision_values` 判断原有互撞。
- **改变当日结果天数**：固定历史中每笔有效正常报价 `bid`，移除当天全部超级出价，再用引擎共用的纯判定重新计算正常报价互撞及赢家；与历史赢家/流局比较。每一天最多计一次，全场汇总，不逐人归因。落空、命中低价或命中本已互撞的价位通常不会改变赢家；当天正常报价被全部狙掉导致流局也可能计入。非法整单转成的正常 0 保持为 0，不重新校验 `raw_bid`，也不沿用原 `collision_values`。只比较当天结果，不推演余额、奖池滚存或未来出价，不改写历史日志。
- **出 0 总笔数**：全部出价记录的 `bid == 0` 次数，包含流局日、超级出价 0 及非法整单转换后的正常 0；玩家明细只计正常出价 0，因此逐玩家相加可能小于聚合总数。0 价获胜次数只计非流局日的获胜价。
