# 模型调用

## 按任务查代码

- 提示文字在 `prompts.py`，文本格式与解析在 `text_output.py`，出价校验和 Agent 组装在 `agent_tasks.py`。
- 任务执行在 `agent_execution.py`，协议和网络请求在 `llm_client.py`。
- 玩家对话历史在 `ai_player.py`，发言、记忆和规划的顺序由 `ai_speech.py` 控制。

## 原则

- 模型直接回复文本，请求不带工具或 JSON schema。格式错误和出价违规共用一次纠错机会，仍失败就让任务失败，由控制器等用户确认补跑。
- 只有可重试的网络或服务错误才重发请求。输出截断算失败。程序错误原样抛出，不当作网络故障重试。
- 客户端在任务自己的事件循环中创建和关闭。
- 任务日志全部写完后才更新玩家状态。
- `strategy` 和记忆只对玩家本人可见，对手只看到公开发言。观众总结不写回玩家历史。已完成任务的 thinking 只留在任务日志里，不再发给模型。
- 局末先公布全员发言，再整理记忆，最后规划下一局。新记忆替换旧记忆和之前的对话，所以提示要让模型保留有效经验、改掉被推翻的判断，只写结论，不写例子和出价记录。最后一局不整理记忆。
- 提示词直接影响比赛效果，改动后要由用户跑一场测试模型赛确认。

模型侧测试在 `tests/ai/`，使用 FunctionModel 或 MockTransport 和假密钥。改阶段顺序时，用 `tests/integration/` 的完整假模型赛验证。
