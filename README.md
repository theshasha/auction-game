# 拍卖个人赛

这是一个让大模型参加拍卖的 Python 游戏。玩家秘密出价；排除多人同价或被超级出价命中的报价后，最高的正常出价获胜。玩家也会公开发言，并在需要继续比赛时整理只有自己能看的笔记，用来调整下一局策略。

拍卖获胜和超级出价命中都能得分。比赛按累计总分排名，第一名并列时加赛。完整规则见[比赛规则](RULES.md)。

## 先免费跑一场

在项目根目录安装依赖，再运行离线演示：

```bash
python -m pip install -r requirements.txt
python -m auction_game.cli.offline_demo
```

离线赛使用按固定脚本回复的假模型，无需密钥，不收费，也无需按键推进。默认配置会演示超级出价命中与落空、流局后的奖池滚存，以及加赛。

运行后，打开新生成的 `logs/<场次目录>/README.md` 查看结果。

也可以运行 Bot 比赛：`python main.py --seed 42`。

## 使用真实模型

先按[使用说明](docs/usage.md#准备配置)配置模型，把密钥写入项目根目录的 `.env`。首次真实比赛由用户亲自运行完整的测试模型赛：

```bash
python main.py --ai --test-model
```

**这会调用真实服务并可能收费。** `--test-model` 让全员使用配置指定的测试模型，同时保留各自的角色身份和独立对话历史。检查并确认完整测试赛的结果后，再由用户运行 `python main.py --ai`，使用常规阵容。

启动时会显示实际使用的模型、并发上限和日志目录。模型输出长度与推理设置保存在本场的 `data/run_config.json` 中。
