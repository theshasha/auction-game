# 目标

给 analyze.py 增加按玩家分组的统计输出段，把目前需要临时脚本手工计算的玩家维度数据（胜场、超级出价效率、撞车放血、平均出价、局末余额）变成 analyze.py 的内建输出。

# 范围

- 修改 analyze.py：新增玩家维度统计段（每局胜场矩阵 + 玩家明细行）
- tests/ 补充或调整零网络测试

# 非目标

- 不改日志格式（jsonl / match_*.json 结构不变），analyze.py 保持只读
- 不改 RULES.md 与任何游戏规则
- 不做多场次目录聚合输入（Q2 用户确认）：analyze.py 保持单场目录输入，跨场对比以后需要时另开 change
- 不改动现有聚合输出的内容与顺序，只在其中插入新统计段

# 验收示例

- analyze.py 输出玩家维度统计段，覆盖该场全部 6 名玩家，每人包含：总胜场、局冠军数（并列按 1/n 计）、超级出价使用/命中/命中率、撞车放血、平均正常出价、每局局末余额、非法出价笔数、出 0 次数
- 玩家维度统计段包含每局胜场矩阵（每名玩家 × 每局的胜场数明细）
- 玩家维度段对 v7、v5/v6 新格式与旧格式日志均可运行，缺失数据（如旧格式无 super_uses 命中率）按 analyze.py 现有版本自适应风格降级，不报错
- 全量零网络；`python3 -m pytest tests/ -q` 全绿

# 约束与不变量

- 全量零网络
- 复用 analyze.py 现有版本检测（rules_version / collision_values）与 FALLBACK 常量模式
- 玩家名单取自日志本身（与现有 player_names 推导一致），不读 config.yaml
- 输出保持 analyze.py 现有纯文本 print 风格
- 统计口径必须与聚合段一致：撞车放血只计正常出价、出价均值刨除流局日、局末余额复用 recompute_remaining_coins

# 决策

- 工作区：当前目录（工作区干净、无其他 active change，采用 Runtime 默认 current）
- Q1（用户确认）：完整版指标集合——核心六项（总胜场、局冠军数、超级出价使用/命中/命中率、撞车放血、平均正常出价、每局局末余额）+ 违规与出 0（非法出价笔数、出 0 次数）+ 每局胜场矩阵
- Q2（用户确认）：不做多目录聚合，保持单场输入
- 玩家排序：按总胜场降序（与本次临时分析的展示一致）
- 统计段位置：聚合经济块（撞车放血 / 超级出价行）之后、「单局 ≥3 胜场」列表之前
- 局冠军口径：每局胜场最高者为局冠军，第一名并列时按 1/n 计入（与临时分析一致；正式规则只有全场总排名，局冠军仅为统计视角）
- 旧格式降级口径：旧格式无 super_uses 字段，超级出价使用次数可从 bids 的 is_super 统计，命中率不可得时显示降级标记
