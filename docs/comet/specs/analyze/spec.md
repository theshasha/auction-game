# Capability: analyze（analyze.py 对战日志统计）

## 概述

analyze.py 统计单场对战目录（logs/<时间戳>_<bot|ai>）的 match_*.json 并打印聚合统计。
本规格定义其中「玩家维度统计段」的完整行为；analyze.py 既有聚合段的内容与顺序不变，
玩家维度段插入在聚合经济块（撞车放血 / 超级出价行）之后、「单局 ≥3 胜场」列表之前。

## 玩家维度统计段

### 版本检测与降级

- 沿用 analyze.py 现有版本检测：新格式 = 首日含 `collision_values`；v6+ = `rules_version` ∈ {v6, v7}；其余为旧格式。
- 旧格式日志缺少 `super_uses` 明细：超级出价「使用次数」从 bids 的 `is_super` 统计；「命中率」不可得，显示降级标记（`—`），不得报错。
- 其余指标在三种格式下均可计算。

### 每局胜场矩阵

- 每名玩家一行、每局一列，单元格为该玩家在该局的胜场数（来自 match 的 `wins` 字段）。
- 覆盖本场全部局（含加赛局，如有）。

### 玩家明细行

每名玩家一行，按总胜场降序排列，包含以下指标（口径与聚合段一致）：

1. 总胜场：match `wins` 跨局合计。
2. 局冠军数：每局胜场最高者为局冠军；第一名并列时每人按 1/n 计入（局冠军仅为统计视角，与正式规则的加赛判定无关）。
3. 超级出价使用 / 命中 / 命中率：新格式（含 v6/v7）从 `super_uses` 统计使用与命中；旧格式使用次数从 bids 的 `is_super` 统计，命中率显示 `—`。
4. 撞车放血：该玩家因撞车被没收的正常出价金币合计（口径与聚合段「撞车放血」一致，只计正常出价）。
5. 平均正常出价：该玩家非流局日全部有效正常出价的均值（刨除流局日，与聚合段口径一致）。
6. 每局局末余额：复用 `recompute_remaining_coins`，逐局列出。
7. 非法出价笔数：bid `status == "illegal"` 的次数。
8. 出 0 次数：正常出价为 0 的次数。

### 输出风格

- 纯文本 print，与 analyze.py 现有输出风格一致；玩家名单取自日志本身，不读 config.yaml。

## 验收场景

Scenario: 对最新 v7 场次运行 `python3 analyze.py`，输出包含玩家维度统计段：6 名玩家每人一行含全部八项指标，并有每局胜场矩阵；抽查数值与 match_*.json 重算一致。

Scenario: 对一个旧格式（无 `collision_values`、无 `rules_version`）日志目录运行 analyze.py，玩家维度段正常输出且超级出价命中率显示降级标记，进程不报错。

Scenario: 全部改动零网络；`python3 -m pytest tests/ -q` 全绿，且 analyze.py 既有聚合输出内容与顺序未被改变。
